# Apple app

Swift and SwiftUI, targeting Apple Vision Pro.

The home screen contains connection status, **Pair** or **Connect**, and
Settings. Pairing completes back at Connect. Fullscreen belongs to the
connected desktop and requests Immersive Mode explicitly.

Build the first pairing slice here in the real app target. No application
source has been added yet. Do not copy the previous project's client or
create a separate sample application to stand in for this app.
